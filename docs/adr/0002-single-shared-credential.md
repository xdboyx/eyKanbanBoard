# 不建使用者帳號，整個系統只有一組共用帳密

系統沒有使用者帳號的概念：帳號與密碼各只有一組，設定在 Cloudflare 的環境變數（`APP_USERNAME` 為一般變數，`APP_PASSWORD` 與 `SESSION_SECRET` 為 Secret），所有知道帳密的人登入後看到並編輯同一個看板。這是為了讓第一版不需要註冊、帳號管理與權限設計。

## Consequences

- 無法得知是誰做了哪一個修改，也無法做個別權限；任務的負責人只是自由文字，不對應帳號。
- 更換密碼或 `SESSION_SECRET` 會讓所有人同時登出。
- 若之後需要多使用者，需要新增帳號儲存、session 與每個人的身分，這不是小改動。
